# Mentoria_AI_Engineer

Trilha completa para se tornar **Senior AI Engineer** estudando só por este repositório. As seções seguem a ordem de estudo: da base até o nível sênior.

> 🗓️ Última revisão: novembro/2026. IA muda toda semana, então as seções de **modelos**, **frameworks** e **ferramentas** devem ser revisadas a cada trimestre.
>
> 💸 Todos os links são gratuitos. As APIs de modelos (Claude, OpenAI, Gemini) cobram por uso, mas a documentação é aberta; para praticar sem custo, use modelos abertos com Ollama ou os planos gratuitos dos provedores.
>
> 🌎 A maior parte do material de ponta em IA está em inglês. Onde existe uma boa versão em português, ela foi priorizada.
